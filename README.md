# Ferrari Club España

Web oficial del Ferrari Club España. Next.js 16 + Prisma + Neon Postgres + Vercel.

## Desarrollo local

```bash
npm install
npm run dev
```

Abre [https://club-ferrari-espana.vercel.app](https://club-ferrari-espana.vercel.app).

## Estructura

- `src/app/` — páginas y rutas API (Next.js App Router)
- `src/components/` — componentes React
- `prisma/` — esquema y migraciones de base de datos
- `public/` — assets estáticos
- `scripts/` — seeds y utilidades de BD
